## ✨ Features

- 🗺️ **Continent Selection**: Explore the world by navigating through major regions.
- 🏳️ **Country Details**: In-depth information about individual countries.
- 🔐 **Secure Access**: Protected routes with Angular Guards for sensitive content.
- ⚡ **Performance**: Optimized lazy loading of standalone components.
- 📱 **Responsive Design**: Seamless experience across mobile, tablet, and desktop devices.
- 🎨 **Modern UI**: Polished interface with clean layouts and consistent color palettes.

---

## 🛠️ Tech Stack

- **Core**: Angular (Standalone Components)
- **State Management**: Angular Signals & RxJS
- **Monorepo**: Nx Build System
- **Styling**: SCSS (Global color variables & BEM methodology)
- **Deployment**: Netlify

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (latest LTS)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Falinowy/continents.git
   ```
2. Navigate to the project directory:
   ```bash
   cd continents
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm start
```
Navigate to `http://localhost:4200/`. The app will automatically reload on source changes.

### Build

Create a production-ready bundle:
```bash
npm run build
```
Build artifacts will be stored in the `dist/` directory.
